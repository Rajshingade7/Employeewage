# Employee Wage

A JavaScript-based project implementing employee wage computation logic. Covers various use cases for calculating wages based on attendance, hours worked, and different pay conditions.

## Features

- Daily wage calculation based on work hours
- Monthly wage computation with attendance tracking
- Part-time and full-time wage differentiation
- Wage breakdown and summary reports
- Modular, reusable JavaScript functions

## Tech Stack

- **JavaScript** — Core logic and implementation

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Rajshingade7/Employeewage.git
   cd Employeewage
   ```

2. Run with Node.js:
   ```bash
   node index.js
   ```
